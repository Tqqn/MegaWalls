# MegaWalls
This is a remake of the popular Minigame MegaWalls from Hypixel, coded for fun and portfolio purposes.

## Overview
MegaWalls is a game where four teams spawn on a map, each with their own base separated by walls. After a certain preparation phase, the wall are removed, allowing teams to attack each other. Players can respawn after being killed. Each team has a wither that enemies can kill. When a team's wither is killed, that team loses the ability to respawn. Once all withers are dead, a deathmatch begins. The team with the most "final" kills (kills that occur when the killed player's wither is dead) wins, or the last surviving team wins.

## Features
- Dynamically map choosing
- Custom Classes
- Loot-Chest System
- Player Ender-Chests
- Coming more soon.
